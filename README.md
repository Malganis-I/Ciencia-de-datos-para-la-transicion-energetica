# Ciencia-de-datos-para-la-transicion-energetica
Cuadernillos de python en Jupyter o Google Colab para replicar actividades del SIMEM como el establecimiento del precio del mercado de la energía.
El archivo .iynpb acerca de la oferta muestra todo lo necesario para la construcción de la curva de oferta agregada para un día y ára un mes completo del mes de octubre de 2025.
